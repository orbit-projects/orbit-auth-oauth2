# Orbit Auth OAuth 2.0 and OpenID Connect roadmap

This package is pre-alpha. Roadmap direction is evidence-driven and has no dated delivery promises. The current implemented scope is the package [README](README.md), [architecture guide](docs/architecture/overview.md), and source tree; the package name alone does not imply an implemented integration or feature.

## Priorities

1. Keep the public contract, package dependencies, and Core/capability boundaries explicit.
2. Add focused tests and update documentation whenever behavior or configuration changes.
3. Gather compatibility, lifecycle, failure, and operational evidence for each provider or runtime the package claims to support.
4. Close hosted CI, security, artifact integrity, and provenance requirements before a stable release.

Proposed providers and capabilities are not commitments. They become supported only after implementation, documentation, tests, and review are present in this repository.
